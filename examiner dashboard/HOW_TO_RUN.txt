Music Examination Management System — RUN THIS ZIP

IMPORTANT
After extracting this ZIP, package.json is in the SAME folder as this file.
You do not need to enter another nested project folder.

Prerequisite
Install Node.js 22.12 or newer (LTS recommended).

RUN
1. Extract the ZIP completely.
2. Open the extracted folder in VS Code.
3. Open Terminal -> New Terminal.
4. Confirm that the terminal folder contains package.json.
5. Run:

   npm install

6. Then run:

   npm run dev

7. Open the Local URL printed by Vite, normally:

   http://localhost:5173/
